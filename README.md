# SkillCraft Technology – Task 01
## Responsive Landing Page 🌐

Welcome to my **Responsive Landing Page** project, developed as **Task 01** during my Web Development Internship at SkillCraft Technology.

This project demonstrates a modern, responsive website with a fixed navigation bar, smooth scrolling, interactive hover effects, and a clean dark-themed user interface.

## 🏠 Home
The Home section introduces the website with the headline **“Build. Create. Grow.”** and provides quick navigation to the Projects and Contact sections.

## 👤 About
The About section explains the purpose and features of the landing page, including responsive design, fixed navigation, hover effects, and scroll interactions.

## 🛠️ Services
The Services section highlights the web development features and services presented on the website, focusing on modern, interactive, and mobile-friendly web design.

## 💻 Projects
The Projects section showcases project-related information and provides visitors with an overview of the work presented on the landing page.

## 📩 Contact Me
The Contact section provides a place for visitors to find contact information or reach out for collaboration and professional opportunities.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Fixed navigation bar
- Smooth scrolling between sections
- Interactive navigation links
- Hover effects on menu items and content cards
- Modern dark theme with teal highlights
- Clean and user-friendly interface
- Separate Home, About, Services, Projects, and Contact sections
